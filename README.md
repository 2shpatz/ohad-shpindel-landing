# אוהד שפינדל — האתר האישי

דף נחיתה אישי בעברית (RTL), ללא תלויות וללא build step. מתארח חינם ב‑Cloudflare Pages.

Personal Hebrew landing page. Vanilla HTML/CSS/JS, zero dependencies, no build step —
same conventions as the other sites under `landing_pages/`.

## מה צריך למלא (התחל מכאן)

כל התוכן של האתר נמצא בקובץ אחד: **`public/assets/js/content.js`**.
אין צורך לגעת ב‑HTML או ב‑CSS.

חפש בקובץ את המילה `TODO_` — כל מופע כזה הוא משהו שצריך להחליף:

|---|---|---|
| מפתח לטופס יצירת קשר | `contact.web3formsKey` | נכנסים ל‑[web3forms.com](https://web3forms.com), מקלידים אימייל, מקבלים מפתח. ללא הרשמה, 30 שניות. |
| חלון בחירת סכום | `support.options[].amounts` | לא חובה. עם הבלוק הזה הכפתור בכרטיס פותח חלון בחירת סכום במקום לקפוץ ישר לקישור: `presets` הם הסכומים המוצעים, `defaultAmount` הסכום המסומן מראש, ו‑`urlTemplate` הוא הקישור שנבנה - `{amount}` מוחלף במספר (למשל `https://www.paypal.com/donate/?business=<merchant-id>&currency_code=ILS&amount={amount}`). בלי הבלוק הכפתור נשאר קישור רגיל ל‑`url`. |

| אימייל | `meta.email` | |
| PayPal | `support.options[paypal].url` | קישור תרומה: `https://www.paypal.com/donate/?business=<merchant-id>&currency_code=ILS`. את ה‑`merchant-id` (מזהה ציבורי, לא אימייל) אפשר לשלוף מדף ה‑PayPal.Me: `curl -sL https://paypal.me/<slug> | grep -o '"payerId":"[^"]*"'`. **לא** להחזיר קישור `paypal.me/...`: הוא רשום אצל אפליקציית PayPal כ‑app link על כל הנתיבים, ולכן בנייד עם האפליקציה מותקנת הדף לעולם לא נפתח - האפליקציה קופצת, מתעלמת מהסכום ונשארת במסך הבית. `/donate` לא נמצא ברשימה הזו, נפתח בדפדפן עם הסכום והנמען מוכנים, ותומך גם בתשלום בכרטיס בלי חשבון PayPal. |
| Buy Me a Coffee | `support.options[bmc].url` | קישור מהפרופיל שלך |

| טקסט "קצת עלי" | `about.paragraphs` | כל מחרוזת = פסקה |
| פרויקטים | `projects` | ראה למטה |
| תמונה | `meta.photo` | שים קובץ ב‑`public/assets/img/` ורשום `'assets/img/ohad.webp'` |

**האתר עובד גם לפני שממלאים.** כל דבר שלא הוגדר פשוט לא מוצג — אין קישורים שבורים
ואין טפסים שמתחזים לעבוד. הטופס אומר במפורש שהוא לא מחובר עדיין.

### להוסיף פרויקט

מוסיפים אובייקט למערך `projects`. כל פרויקט מקבל כרטיס וגם דף משלו בכתובת `#projects/<id>`:

```js
{
  id: 'my-project',              // אנגלית, בלי רווחים — זו הכתובת
  title: 'שם הפרויקט',
  blurb: 'משפט אחד לכרטיס',
  tags: ['Python', 'אוטומציה'],
  image: 'assets/img/proj.jpg',  // או null
  body: ['פסקה ראשונה', 'פסקה שנייה'],
  links: [{ label: 'לאתר', url: 'https://…', primary: true }],
}
```

### קרוסלת תמונות בדף פרויקט

בלוק `gallery` בתוך פרויקט מוסיף רצועת צילומי מסך בין הכותרת לכפתור ההורדה.
התמונה המרכזית מלאה, זו שלפניה וזו שאחריה שקופות למחצה בצדדים, ולחיצה על
המרכזית פותחת אותה בגדול. אין `gallery`? אין קרוסלה.

```js
gallery: {
  title: 'הצצה לאפליקציה',
  hint: 'לחצו על תמונה להגדלה',
  items: [
    {
      src:  'assets/img/spill-it-out/home.webp',       // 760px, זו שברצועה
      full: 'assets/img/spill-it-out/home-full.webp',  // 1600px, רק בהגדלה
      caption: 'מסך הבית - כל המשפחות במקום אחד',      // גם הכתובית וגם ה-alt
    },
  ],
}
```

**שני קבצים לכל תמונה, בכוונה.** הקטן הוא מה שנטען עם הדף (שמונה כאלה יחד
שוקלים 156KB), והגדול נטען רק כשמישהו באמת מגדיל. להוספת צילום מסך חדש:

1. שומרים את ה-PNG המקורי ב-`sources/spill-it-out-screenshots/` שמחוץ ל-`public/`
   (הקבצים המקוריים כבדים, 10MB, ואין סיבה שייפרסו).
2. מייצרים שתי גרסאות WebP ל-`public/assets/img/spill-it-out/` ברוחב 760
   (איכות 74) וברוחב 1600 (איכות 78).
3. מוסיפים שורה ל-`items` עם שני הנתיבים והכתובית.

המסגרת היא 16/9 ב-`cover`, כך שצילום מסך רחב מאבד אחוזים בודדים מהצדדים.
צילום מסך **גבוה** מ-16/9 (למשל חלונית דיאלוג) ייחתך משמעותית, ולכן מרחיבים
אותו ל-16/9 לפני הייצוא וממלאים את השוליים בעותק מטושטש ומוגדל של עצמו -
כך הוא נכנס לרצועה באותה צורה כמו כל השאר בלי לאבד כלום.

## הרצה מקומית

```bash
cd public && python3 -m http.server 8099     # → http://localhost:8099
```

או, אם רוצים גם את הכותרות של Cloudflare (`_headers`):

```bash
npx wrangler pages dev public                 # → http://localhost:8788
```

## פריסה

האתר נפרס כ‑**Worker עם static assets** (לא Pages). הקובץ `wrangler.toml`
מגדיר `[assets] directory = "./public"` ובלי `main`, כך שכל בקשה מוגשת ישירות
מהתיקייה `public/`. הקובץ `_headers` ממשיך לעבוד.

### מהמחשב

```bash
npx wrangler deploy
```

בפעם הראשונה תתבקש להריץ `npx wrangler login`.

### מ‑Cloudflare (חיבור ל‑git)

בהגדרות ה‑build:

| שדה | ערך |
|---|---|
| Build command | **להשאיר ריק** |
| Deploy command | `npx wrangler deploy` |
| Root directory | הנתיב לתיקייה שמכילה את `wrangler.toml` |

> **לא** להשתמש ב‑`npx wrangler pages deploy` בתוך build של Cloudflare.
> הטוקן ש‑Cloudflare מזריק אוטומטית ל‑build מורשה ל‑Workers ולא ל‑Pages,
> ולכן הפקודה נכשלת עם `Authentication error [code: 10000]` — גם אם החשבון
> הוא Super Admin.

## שכבת הארקייד (`arcade.js` + `arcade.css`)

דמויות פיקסל מסתובבות בעמוד, מציצות מאחורי לשוניות וכרטיסים, נופלות לאט מלמעלה
ומסתובבות להסתכל על הסמן או על המקום שנלחץ. בנוסף יש **פטיש** ששובר מילים —
ואת הדמויות עצמן — לפיקסלים.

- **כיבוי/הדלקה**: כפתור "דמויות" בפינה. הבחירה נשמרת ב‑`localStorage`.
- **הפטיש**: כפתור "פטיש". כשהוא פעיל, לחיצה על טקסט או על דמות שוברת אותם.
  **סגירת הפטיש מחזירה את הכול** — הפיקסלים חוזרים למקומם והטקסט שב.
- **צפיפות**: `arcade.density` ב‑`content.js` — `'calm'` (2) / `'normal'` (4) / `'busy'` (6).
  במובייל תמיד פחות. `arcade.enabled: false` מכבה לגמרי.
- **הפחתת תנועה**: מי שהגדיר במערכת ההפעלה "הפחתת תנועה" לא מקבל את השכבה בכלל —
  לא קנבס, לא כפתורים, ולא לולאת אנימציה.

הדמויות מאוחסנות כרשתות פיקסלים ב‑`arcade.js` (בלי קבצי תמונה). להוסיף דמות =
להוסיף אובייקט אחד ל‑`SPRITES`.

**מי יש שם (13 דמויות):** שתי רוחות מבוך, אוכל־הנקודות, שלושה סוגי פולשים
(סרטן, דיונון, תמנון), עב״ם, צפרדע, חללית, הנסיך, רובוקופ, מריו, והחתול.

**קומת הקרקע:** הנסיך, רובוקופ, מריו והחתול תמיד למטה. הם הולכים, קופצים,
ומסתובבים בקצוות במקום לצאת מהמסך. שוברים אחד מהם בפטיש — הוא חוזר תוך כמה שניות.

**החתול** מתנהג אחרת מכולם: הוא בוחר אלמנט אמיתי בעמוד (כרטיס, כפתור, כותרת,
פסקה), הולך אליו, קופץ עליו ונוחת עליו. אחרי ~7 שניות למעלה הוא מפסיק לטפס,
יורד מהקצה ונופל בחזרה לרצפה. הפיזיקה אמיתית: כוח הקפיצה מחושב בדיוק לגובה
היעד. רשימת ה"פלטפורמות" מתרעננת כל 0.4 שניות ולא בכל פריים — `getBoundingClientRect`
על עשרות אלמנטים 60 פעם בשנייה היה מכריח חישוב layout מחדש.

> **לתשומת לב:** הדמויות מבוססות על דמויות ארקייד מוכרות משנות ה‑70–80, לבקשה
> מפורשת. המקור שלהן הוא סימני מסחר פעילים של Bandai Namco‏, Taito ו‑Nintendo.
> החלפה לעיצוב מקורי = שינוי אובייקט אחד ב‑`SPRITES`, בלי נגיעה בשאר הקוד.

### החלטות שכדאי להכיר

- **ניווט**: עמוד אחד, טאבים מתחלפים במקום. הכתובת מתעדכנת (`#about`, `#projects/<id>`)
  אז אפשר לשתף קישור ישיר וכפתור "אחורה" עובד. משתמש ב‑View Transitions API
  איפה שיש, עם fallback ב‑CSS.
- **פונטים**: כל האתר ב‑**Tel Aviv Eclectic no.2** — שני קבצים, אחד לעברית ואחד
  ללטינית וספרות. Heebo נשאר רק כ‑fallback אחרון ולא נטען בפועל.
  > ⚠️ **שתי שורות ה‑`unicode-range` ב‑`base.css` הן קריטיות.** כל אחד משני
  > הקבצים מצהיר ב‑cmap גם על הכתב **השני** וממפה אותו לגליפים **ריקים**:
  > - קובץ הלטינית מצייר "אוהד שפינדל" עם 0 פיקסלים אבל תופס 105px רוחב
  > - קובץ העברית מצייר "Ohad ABC" עם 0 פיקסלים
  >
  > הדפדפן חושב שיש כיסוי, לא עובר ל‑fallback, וחצי מהטקסט באתר פשוט נעלם —
  > אבל ממשיך לתפוס מקום, כך שזה נראה כמו באג פריסה ולא כמו פונט חסר.
  > הטווחים מוגדרים בלי חפיפה. **אחרי כל שינוי שם — לבדוק את שני הכתבים.**
  >
  > שניהם מוגדרים `font-weight: 400` (משקל סטטי יחיד, בלי ציר משתנה). הגדרת
  > `100 900` הייתה מבטלת bold סינתטי ומשטחת את כל הכותרות (נמדד: 0% דיו נוסף
  > במשקל 800, מול 23%+ בהגדרה הנכונה).
- **RTL**: דרך CSS logical properties (`margin-inline-start` וכו') ולא left/right,
  כך שהכיווניות נכונה מעצם המבנה.
- **`prefers-reduced-motion`**: מכובד במלואו — כל האנימציות נכבות ו‑`motion.js`
  לא מחבר מאזינים בכלל.
- **מובייל**: סרגל טאבים תחתון (נגיש לאגודל), מכבד `safe-area-inset`.
  אפקטים של עכבר רצים רק ב‑`(pointer: fine)`.
- **משקל**: 223KB בסך הכול — 46KB טקסט מכווץ + 98KB פונטים + 79KB תמונה. אפס תלויות.
  התמונה היא WebP (הומרה מ‑JPEG של 115KB). Heebo עדיין נפרס (42KB) אבל כמעט
  אף פעם לא נטען — אפשר למחוק אותו אם רוצים לחסוך.

## בדיקות

לא הוגדר framework לבדיקות. אימות ידני:

```bash
cd public && python3 -m http.server 8099
```

ואז לוודא: מעבר בין כל הטאבים, `#projects/<id>` בטעינה ישירה, כפתור אחורה,
hash לא מוכר → "עליי", הטופס עם שדות ריקים ועם אימייל לא תקין,
ו‑"הפחתת תנועה" בהגדרות מערכת ההפעלה.

ולקרוסלת התמונות: חצים ונקודות, לחיצה על תמונה בצד (מביאה אותה למרכז) לעומת
לחיצה על המרכזית (פותחת אותה על מסך מלא), חצי המקלדת וגם Escape בתוך התצוגה
המוגדלת, וכפתור אחורה כשההגדלה פתוחה.

בתצוגה המוגדלת: לחיצה על התמונה עצמה מעלימה את ה-X ואת שורת הכתובית והחצים
לצפייה נקייה, ולחיצה נוספת מחזירה אותם. גם כשהם מוסתרים - חצי המקלדת עדיין
מדפדפים ו-Escape עדיין סוגר, וכל פתיחה מחדש מתחילה עם הלחצנים גלויים.

בנייד בנוסף: משיכת אצבע ימינה מקדמת לתמונה הבאה ושמאלה חוזרת אחורה (האצבע
מזיזה את התמונות, לא מצביעה עליהן), ובתצוגה המוגדלת התמונה כולה נראית מקצה
לקצה וההתקרבות לפרטים היא בצביטה (pinch) - לכן אין לשים `user-scalable=no`
ב‑`index.html`, זה ישבור את ההגדלה.
